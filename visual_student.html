Data Structure: Maps & Nodes

In Java, a HashMap maps unique Keys to specific Object Nodes in memory. When you call studentMap.put(101, new Student(...)), it creates a Key (101) which acts as a pointer directing to a dynamically allocated Student Node in the Heap Memory.
