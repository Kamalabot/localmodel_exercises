# Local Model Training: Advanced Excel & Automation

Welcome to the local model training exercises. These exercises are designed to help you master AI-assisted workflows using local LLMs and coding agents.

## 🚀 Choose Your Level

### [Level 1: Excel & Pi for Excel](./L1_Excel_Exercises.md)
*   **Focus:** Direct spreadsheet interaction, natural language formulas, and data cleaning.
*   **Tools:** Excel + Pi for Excel + LM Studio.
*   **Exercises:** Data Scavenging, Formula Architecting, Data Transformation, and Logic Distillation.

---

### [Level 2: Advanced Scripting & Automation](./L2_Scripting_Exercises.md)
*   **Focus:** Data engineering, automated reporting, and web automation logic.
*   **Tools:** Python (Pandas/Matplotlib), JavaScript, Coding Agents.
*   **Exercises:** Multi-source mergers, Sentiment Analysis, Chart Generation, and JSON Processing.

---

## 🛠️ Global Prerequisites
1.  **LM Studio:** For running local inference.
2.  **Coding Agent:** (e.g., Antigravity, Cline, or VS Code Copilot) to assist with script writing in Level 2.
3.  **Exercise Data:** All raw materials are located in the `/exercise_data` folder.
