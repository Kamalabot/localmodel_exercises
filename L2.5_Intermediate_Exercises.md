# Level 2.5: Intermediate Automation (PDFs & Web Scraping)

This level bridges the gap between basic scripting and full integration by focusing on two of the most common automation tasks: handling unstructured document data (PDFs) and extracting information from the web.

## Phase 1: PDF Automation
Learn to read, manipulate, and generate PDF documents.

### 1. Exercise P11: The PDF Text Miner
*   **Goal:** Extract structured text from a document.
*   **Task:** Write a Python script using `PyPDF2` or `pdfminer.six` to read `exercise_data/L2.5_data/sample_report.pdf`. Extract the "Executive Summary" and save it as a separate text file.

### 2. Exercise P12: The Invoice Merger
*   **Goal:** Batch processing and file manipulation.
*   **Task:** Take three PDF files (`invoice_01.pdf`, `invoice_02.pdf`, `invoice_03.pdf`) from the data folder and merge them into a single file named `Quarterly_Invoices.pdf` with a custom cover page.

### 3. Exercise P13: The Tabular Data Extractor
*   **Goal:** Handling complex layouts.
*   **Task:** Use `camelot-py` or `tabula-py` to extract a pricing table from `exercise_data/L2.5_data/product_catalog.pdf`. Export the table directly to a `catalog.csv` file.

### 4. Exercise P14: The Security Wrapper
*   **Goal:** Metadata and security.
*   **Task:** Write a script that loops through all PDFs in a directory and:
    1. Adds a "INTERNAL USE ONLY" watermark to each page.
    2. Encrypts the file with a password found in `exercise_data/L2.5_data/passwords.json`.

## Phase 2: Web Scraping & Browser Automation
Moving beyond local files to the live web.

### 5. Exercise W1: The Static News Scraper
*   **Goal:** Understanding HTML structure.
*   **Task:** Use `BeautifulSoup` and `requests` to scrape the headlines and timestamps from `exercise_data/L2.5_data/mock_news_site.html`. Save the results as a JSON list.

### 6. Exercise W2: The Hidden API Hunter
*   **Goal:** Efficient data gathering.
*   **Task:** Instead of scraping HTML, identify the background API call for a "Load More" button. Write a script to fetch 5 pages of data from the simulated endpoint `https://api.mock-shop.com/products?page=X` and save to CSV.

### 7. Exercise W3: The Dynamic Price Tracker
*   **Goal:** Handling JavaScript-heavy sites.
*   **Task:** Use **Playwright** or **Selenium** to open a dynamic page where prices are loaded via JS. Wait for the selector `.price-tag` to appear, then grab the value and log it.

### 8. Exercise W4: The Automated Login Bot
*   **Goal:** Session management and interaction.
*   **Task:** Write a Playwright script that:
    1. Navigates to a login page.
    2. Enters credentials from an environment variable.
    3. Clicks "Login".
    4. Takes a screenshot of the "Success" dashboard and saves it as `dashboard_proof.png`.
